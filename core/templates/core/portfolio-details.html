Duka Online Storefront

Client: Savanna Crafts Co.
The problem

The business took orders only through social media messages, so orders were missed, stock levels were guessed and customers waited days for replies.

Our solution

We built an online store with a product catalogue, shopping cart, mobile-money checkout and an order dashboard that shows staff exactly what to pack and ship.

Key results
  • Orders confirmed in minutes instead of days
  • Online sales tripled within six months
  • Stock levels updated automatically with every sale

DjangoPostgreSQLBootstrapM-Pesa Daraja API

ClinicBook Appointments

Client: Mwangaza Family Clinic
The problem

Patients queued for hours because the clinic had no booking system, and many booked patients forgot their appointments.

Our solution

We built a web booking system where patients choose a doctor and time slot, receive SMS reminders, and staff manage the daily schedule from one screen.

Key results
  • Average waiting time cut by 40%
  • Missed appointments down by a quarter
  • Front-desk phone calls reduced by half
Technologies used
DjangoMySQLJavaScriptSMS Gateway API

Key results
  • Report cards delivered online to all parents
  • Fee collection improved by 30%
  • Printing costs cut by over 70%

FarmLink Mobile

Client: Green Valley Farmers Cooperative
The problem

Farmers relied on middlemen to sell their produce and had no way of knowing fair market prices before they sold.

Our solution

We built an Android app that shows daily market prices, lets farmers list produce for buyers and works offline in areas with weak network coverage.

Key results
  • Over 2,000 farmers onboarded in the first year
  • Farmers earned 20% more per sale on average
  • Works offline and syncs when connected
Technologies used
FlutterFirebaseDjango REST FrameworkOffline sync

RideSafe Boda

Client: Mji Riders SACCO
The problem

The SACCO had no record of members' trips, cash payments made daily savings hard to track, and riders had no quick way to call for help.

Our solution

We built a mobile app that logs trips, takes cashless fares, deducts daily savings automatically and includes a one-tap emergency button that shares the rider's location.

Key results
  • Member savings contributions up by 35%
  • Emergency response time under 10 minutes
  • Every trip and payment recorded digitally
Technologies used
React NativeNode.jsGoogle Maps APIM-Pesa Daraja API

Secure Cloud Migration

Client: Highland Microfinance
The problem

Core systems ran on a single office server that often went down, and backups were made by hand, putting customer records at risk.

Our solution

We moved the core systems to the cloud, set up automatic daily backups and monitoring, and secured staff access with multi-factor authentication.

Key results
  • System uptime improved to 99.9%
  • Full data recovery possible within one hour
  • Passed the external security audit

AWSDockerPostgreSQLMulti-factor authentication
